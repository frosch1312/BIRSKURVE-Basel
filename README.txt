BIRSKURVE BASEL – GITHUB PAGES VERSION

Dateien:
- index.html = Startseite
- ueber-uns.html = Über uns
- galerie.html = Galerie
- info.html = Info & Fankultur
- kontakt.html = Kontakt
- assets/css/style.css = komplettes Design
- assets/js/main.js = mobiles Menü + Jahreszahl
- assets/img/ = eigene Bilder hier hineinlegen

WICHTIG:
GitHub Pages benötigt index.html im Hauptverzeichnis. Diese Datei nicht umbenennen.

Bilder ersetzen:
1. Bild in assets/img/ kopieren, z.B. kurve.jpg
2. In HTML einen Platzhalter durch folgendes ersetzen:
   <img src="assets/img/kurve.jpg" alt="BIRSKURVE Basel">

Kontaktformular:
GitHub Pages kann selbst keine Mails versenden. Kostenlosen Dienst wie Formspree nutzen.
In kontakt.html steht:
https://formspree.io/f/DEINE-ID
DEINE-ID durch die eigene Formspree-ID ersetzen.

Ticketshop:
In index.html nach https://www.fcb.ch/ suchen und durch den gewünschten direkten Ticketshop-Link ersetzen.
